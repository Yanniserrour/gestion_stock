# 📦 Gestion de Stock

Un logiciel simple et efficace pour gérer les entrées/sorties de stock, avec un système d'archivage automatique.

## ✨ Fonctionnalités
- **Ajout de produits** : Enregistrement facile dans le stock.
- **Vente intelligente** : Sortie de stock avec mise en attente de 3 jours.
- **Archivage automatique** : Les ventes terminées passent en historique tout seules.
- **Calculs financiers** : Visualisation de l'argent "dormant" dans le stock.

## 🛠️ Installation
1. Clonez le dépôt :
   `git clone https://github.com/Yanniserrour/gestion_stock.git`
2. Installez les dépendances :
   `pip install tabulate`

## 🚀 Utilisation
Lancez le programme avec :
`python main.py`
